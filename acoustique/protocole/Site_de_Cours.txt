Description
Vous trouverez dans cet onglet des instructions pour utiliser un code de simulation numérique en acoustique (Pyroomacoustics) qui a été déjà été utilisé par le passé. Si ça vous intéresse, vous pouvez explorer cette voie dans votre laboratoire.

**********

Vous êtes invités à télécharger les fichiers sur GitHub. Les informations pour le laboratoire se trouvent dans le fichier README.MD sur le git. Git a été choisi au lieu de monportail parce qu'il permet de visualiser un Notebook et un .md sans logiciels complémentaire.

GitHub sur lequel se trouvent les instructionsCet hyperlien s'ouvrira dans un nouvel onglet.

Télécharger Python
Pour télécharger Python 3, le plus simple est de télécharger la suite Anaconda. Python est un logiciel permettant aux utilisateurs de publier de "packages". Anaconda permet de telecharger facilement des packages en plus de permettre de télécharger Jupyter Notebook, pycharm et plusieurs autres environnements de programmation.

AnacondaCet hyperlien s'ouvrira dans un nouvel onglet.

Telecharger pyroomacoustics
Il se peut que lorsque vous fassiez:

pip install pyroomacoustics

Un message d'erreur se présente puisque pyroomacoustics utilise des librairies en C++ pour accélérer la vitesse de calcul. Si c'est le cas, sur Windows* vous pouvez télécharger Visual studio Tools** (1.2G) et ça devrait fonctionner.

* Nous cherchons toujours une solution pour Mac.

** Attention il se peut que ça prenne une trentaine de minutes à télécharger. Le lien est: https://visualstudio.microsoft.com/visual-cpp-build-tools/
